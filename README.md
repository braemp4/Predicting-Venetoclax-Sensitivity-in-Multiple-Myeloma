# Predicting-Venetoclax-Sensitivity-in-Multiple-Myeloma

Venetoclax is a BCL-2 inhibitor used off-label to treat multiple myeloma (MM), particularly in t(11;14)+ patients. However, the genomic and transcriptomic features that influence drug sensivity and not fully understood. In this project we use multiomic analysis and ML to uncover biological programs predictive of venetoclax.
